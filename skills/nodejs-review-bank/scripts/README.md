# nodejs-review-bank tools

Invoke them from wherever your agent installed the skill. They find the sibling skills' scripts through their own resolved path, so install all three skills from the same clone, or set `RQ_SCRIPTS` and `NC_SCRIPTS`.

| Tool | Purpose | Notes |
|------|---------|-------|
| `bank.ts` | The bank: `tick`, `sync`, `plan`, `list`, `show`, `present`, `prefetch`, `put`, `set`, `hold`, `defer`, `unhold`, `slot`, `image prune` | Run with no arguments for usage. Node runs it directly (type stripping): built-in modules only, no build. Backs off on the secondary rate limit like `gh_retry`. |
| `lib/` | The modules behind `bank.ts`, which parses the arguments and dispatches: `config.ts` (env and constants), `util.ts` (errors, time, text, files, running commands), `lock.ts` (`Flock` and slot locks), `github.ts` (`gh` and GraphQL), `entry.ts` (the entry format, states, lanes, ranking), `holds.ts` (`wait_for`, hold, and wake), `queue.ts` (the candidates and `plan`), `sync.ts`, `tick.ts`, `prefetch.ts` and `gates.ts` (the dossier), `screen.ts` (the automation screen), `slots.ts`, `images.ts`, and `commands.ts` (`list`, `show`, `present`, `put`, `set`, `hold`, `defer`, `unhold`) | Erasable TypeScript only (no enums, namespaces, or parameter properties), so Node can strip the types. Imports name the `.ts` file. |
| `bin/gh` | `gh` shim: one `gh` call at a time across processes, at least `GH_MIN_GAP` (1) seconds apart. The lock is a `flock`, so a crashed caller can't leave it held. `bank.ts` holds the same lock while it runs `git node metadata`. | `bank.ts` puts `bin/` first on `PATH` for everything it runs, including `build-queue.sh`, `rereview.py`, `discussion.sh`, and `ci-status.sh` |
| `tests/` | Offline tests: a fake `gh` (`fake_gh.py`), a stub `git-node`, a fake `devc.sh` (`fake_devc.py`), a fake container engine for `devc.sh` itself (`fake_engine.py`), a Docker Hub answer from a file, a temporary bank, and stub sibling scripts | `cd scripts && node --test tests/`. `BANK_CMD` sets the command under test (default `node bank.ts`). No network or container engine, and the real bank is never touched. |

Env: `NODE_REVIEW_BANK` (bank directory, default `$XDG_STATE_HOME/nodejs-review-bank`), `NODE_CLONE` (default `~/dev/nodejs/node`), `REPO`, `ME`, `BANK_TARGET` (6), `REFRESH_MINUTES` (120), `LEASE_MINUTES` (120), `SEARCH_SLEEP` (passed through to `build-queue.sh`), `GH_RETRY_SLEEP` (backoff unit in seconds, default 60), `BANK_METADATA` (lanes whose dossier gets `metadata.txt` from `git node metadata`: `cq` (default), `all`, or `off`), `DEVC_IMAGE` (shared with `devc.sh`), `IMAGE_CHECK_MINUTES` (60: how often to ask Docker Hub, and to retry a failed pull or move), `DEVC_HUB_URL` (the Docker Hub tag API URL, derived from `DEVC_IMAGE`), `SCREEN_HOURS` (48: how long a screened PR waits for its author), `DEFER_DAYS` (7: how long a deferred PR waits at most), `REFRESH_MAX_HOURS` (6: refresh the team queue at least this often, even when dormant), `DORMANT_HOURS` (4: no user activity for this long makes the bank dormant), `REFRESH_RETRY_HOURS` and `REFRESH_RETRY_MAX_HOURS` (2 and 8: backoff after failed refreshes), `TICK_BACKOFF_BASE_MINUTES` (20: the loop's cadence) and `TICK_BACKOFF_MAX_MINUTES` (240: cap on the quiet-tick backoff; 0 turns it off).

`bank.ts` writes only to the bank directory and to `refs/review-bank/*` in the node clone, apart from the image work in free slots: `devc.sh pull`, `down`, `build`, and, with `image prune`, `prune`. None of these tools post to GitHub.

**Prereqs:** the `nodejs-review-queue` and `nodejs-contribute` skills, `gh` (authenticated), `git node` from node-core-utils with `~/.ncurc` credentials (for `metadata.txt`), `zsh`, Node.js (tested on v26.13.1), `python3` (for `rereview.py` and the test fakes), and `git` 2.29 or later (`fetch --no-write-fetch-head`).
